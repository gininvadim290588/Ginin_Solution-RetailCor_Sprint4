## 3. Ограничения

| ID | Ограничение |
|----|-------------|
| C-01 | Нельзя останавливать бизнес во время трансформации |
| C-02 | Недопустима миграция по модели Big Bang |
| C-03 | Необходимо обеспечить поэтапную миграцию |
| C-04 | Oracle остается частью платформы на переходном этапе |
| C-05 | Платформа работает в On-Prem инфраструктуре |
| C-06 | Используются физические серверы |
| C-07 | Ресурсы инфраструктуры близки к пределу |
| C-08 | Нельзя нарушить работу оформления заказа, оплаты и доставки |

## 5. Архитектурно значимые пробелы

Во входных материалах отсутствуют следующие требования:

- SLA платформы
- SLO сервисов
- RTO
- RPO
- RPS/TPS
- Peak Load
- p95/p99
- Допустимое время оформления заказа
- Требования к консистентности
- Требования к деградации системы
- Правила Disaster Recovery
- Требования к резервному копированию
- Требования к безопасностиr
